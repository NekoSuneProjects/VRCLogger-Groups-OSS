Dashboard Privacy

Use Of The Bot

You may use VRC Logger only for Discord servers and VRChat groups where you have permission to configure logging, moderation tools, and group automation.

Authorized Administrators

Dashboard access is intended for Discord server owners, administrators, and approved logger staff. By using the dashboard, you confirm that you are authorized to view or manage the selected Discord server and connected VRChat group data.

VRChat Backend Actions

VRChat group actions are sent through a NekoSuneVR controlled backend API and bot account. You are responsible for enabling only the VRChat role permissions needed for your group workflow.

The bot account's group membership visibility is kept hidden automatically where supported by the backend API.

Acceptable Use

Do not use the service for unauthorized access, harassment, impersonation, bypassing group owner decisions, or collecting data from servers or groups you are not authorized to manage.

Admin Responsibilities

Server owners and admins are responsible for their logger configuration, Discord role/channel permissions, VRChat group role permissions, and any notices required for their own community rules.

Data Requests

Requests to delete or correct server/group records should be sent to https://nekosunevr.co.uk/?redirect=discord. Requests must come from a verified Discord server owner/admin or authorized VRChat group operator for the relevant logger setup.

Service Availability

The service is provided as available. Features may change, fail, or be limited by Discord, VRChat, backend API availability, rate limits, permissions, or configuration errors.
