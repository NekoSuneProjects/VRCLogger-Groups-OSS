Privacy Policy

VRC Logger - Last updated May 8, 2026

Dashboard Terms

Who Runs This Service

VRC Logger is operated by NekoSuneVR. The dashboard and VRChat actions use a NekoSuneVR controlled backend API and VRChat bot account.

Data We Process

The dashboard uses Discord login to identify you, check which Discord servers you own, administer, or have approved logger staff access for, and show only the server data you are authorized to access.

The bot processes configured Discord server IDs, VRChat group IDs, group names, logger channel mappings, moderation/audit log records, staff/queue records, user counters, and public VRChat API data needed for logger features.

The service does not collect VRChat passwords, Discord passwords, payment details, private email inboxes, or private VRChat account credentials from dashboard users.

How Data Is Used

Data is used to provide group logging, moderation support, audit review, staff workflows, Discord dashboard access, configured global sharing features, and operational security for servers that enable the bot.

VRChat group membership visibility for the bot account is kept hidden automatically where the backend API allows it.

Who Can Access Data

Dashboard access is limited to Discord users who own or administer the configured Discord server, plus active logger staff added by authorized server operators. Data for one configured server or VRChat group is not intentionally shown to unrelated Discord servers.

Delete Requests

Deletion or correction requests can be sent to NekoSuneVR at https://nekosunevr.co.uk/?redirect=discord.

For Discord server or VRChat group records, requests must come from a verified Discord server owner/admin or an authorized VRChat group operator for that logger setup. If you are not authorized for the group or server, ask the relevant owner/admin to submit the request so authority can be verified.

Retention And Security

Data is retained while needed for active logger operation, security review, support, or configured community features. Access is controlled through Discord authentication, server ownership/admin checks, and local bot configuration.
